Home screen
CUT · 1 MIN
Open the application and remain on Home.
  1. Six featured agents, each tagged with a category (Research, Marketing, Workflow), a complexity level, and the output it produces — report, slides or data table.
  2. View all agents opens the full template picker.
  3. A free-text field accepts a request without selecting a template.

Report outline gate
CUT · 2 MIN
Scroll to the outline card at the foot of the thread.
  1. Each proposed finding is an editable text field.
  2. A checkbox on each row includes or excludes that finding.
  3. Up and down arrows set the order.
  4. Approve & Build commits the outline and starts generation. No rendering occurs before it is pressed.
The outline card exists only between run completion and approval. Approving removes it; producing another takes approximately six minutes.

Deck outline gate
CUT · 2 MIN
Request a deck. Scroll to the deck outline card at the foot of the thread.
  1. Every row carries a slide type: TITLE, STATS, CHART, COMPARISON, STATEMENT, GRID, CTA.
  2. Deck default is a per-row dropdown that overrides the theme for that slide only.

  4. Approve & Build starts the render.
As with the report outline, the card exists only while the deck is unapproved.

Deck editor
Click the pencil icon on the deck card.
  1. Filmstrip on the left, slide canvas in the centre, format and outline panels on the right.
  2. Slide 3 carries a lock badge, indicating it is pinned and excluded from regeneration.
  3. Each outline row shows its slide type. The reference deck has 12 slides across seven types. + Add slide lists all 20 available types.
  4. Each row has a padlock, a delete control and a drag handle.
  5. Orientation is set in the FORMAT panel.
Portrait is sticky. A page reload is required to revert to Landscape.
